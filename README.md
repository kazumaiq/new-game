# AETHER RIFT

A 60fps bioluminescent cosmic arena roguelite built for the web with **TypeScript**, **HTML5 Canvas**, and a **procedural Web Audio API** synthesizer.

## Features
- **Live Attract-Mode Title Screen** with 4 selectable neon chassis palettes (*Cyber Cyan*, *Solar Flare*, *Crimson Oni*, *Bio Matrix*).
- **Tight Twin-Stick / Mouse-Aim Combat**: Phase Dash (`Space` / `Right-Click`) with invulnerability & afterimages, plus **Aether Nova** (`E` / `Shift`) screen-clearing shockwaves.
- **12 Stacking Roguelite Upgrades**: Chain Lightning, Quantum Ricochet, Solaris Orbital Blades, Swarm Micro-Missiles, Phantom Singularity, Siphon Matrix, and more.
- **5 Hostile Archetypes + Boss Encounters**: Swarmers, Splitters, Laser-telegraphed Snipers, Gravity Wardens, and **THE MONOLITH** boss every 5 waves.
- **Zero External Assets**: Procedural synthwave bassline & SFX generated in real time via Web Audio API.
- **Local Hall of Fame** & Shareable Score Cards.

## Run Locally
```bash
npm install
npm run dev
```

## Build for Production
```bash
npm run build
```

Includes a ready-to-use `.github/workflows/deploy.yml` for automatic **GitHub Pages** deployment on push to `main`.
